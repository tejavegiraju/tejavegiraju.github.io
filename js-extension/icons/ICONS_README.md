# Extension Icons

This folder should contain the following icon files for the extension:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels  
- `icon128.png` - 128x128 pixels

## How to Create Icons

You can create icons using any of these methods:

### Option 1: Online Icon Generator
1. Visit a favicon/icon generator website like:
   - https://favicon.io/
   - https://realfavicongenerator.net/
2. Upload a music/audio themed image or use their icon library
3. Generate and download the icons
4. Rename them to match the required names above

### Option 2: Image Editor
1. Use any image editor (Photoshop, GIMP, Paint.NET, etc.)
2. Create square images with the dimensions above
3. Use a music note, headphones, or speaker icon design
4. Save as PNG format with transparency

### Option 3: Use Emoji/Unicode
1. Screenshot or save a music emoji (🎵, 🎶, 🎧, 🔊)
2. Resize to the required dimensions
3. Save as PNG files

### Temporary Solution
For testing purposes, you can use solid colored squares or simple geometric shapes. The extension will work without fancy icons, but they improve the professional appearance.

## Icon Design Tips
- Use a simple, recognizable symbol (music note, play button, headphones)
- Make sure it's visible at small sizes (16x16)
- Use high contrast colors
- Consider the background (make it transparent or use a solid color)
- Keep it consistent across all sizes
